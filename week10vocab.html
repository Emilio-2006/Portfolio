placeholder (html input attribute)

The placeholder attribute specifies a short hint that describes the expected value of an input field

form method post

Specifying a value of POST means the browser will send the data to the web server to be processed.

background-repeat

The background-repeat property sets if/how a background image will be repeated.

css specificity order: (!important, id, inline, class)

In CSS, specificity determines which styles take precedence when multiple rules target the same element.

maxlength (html input attribute)

The maxlength attribute specifies the maximum number of characters allowed in the < input > element.
