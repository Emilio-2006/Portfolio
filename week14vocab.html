Vocabulary Page Week 14

Wireframe

Your basic layout for any planning via user interface and what it is to look like on the page.

Sitemaps visual

is a file where website owners provide information about the pages videos, and other files on their site and the relationship between them.

Website content categories and taxonomy

Website content categories are broad groupings of content, while taxonomy is the structured system used to organize and classify that content into categories and subcategories, improving navigation and user experience.

User story

A user story is a small unit of development made to accomplish a specific goal in a project

mood board

A tool thats used to elements and textures, colors, images, and style.

Wurman's LATCH

Wurman's LATCH is a framework for organizing information, standing for Location, Alphabet, Time, Category, and Hierarchy

sans-serif fonts serif fonts

In typography, serif fonts feature small decorative strokes or "serifs" at the ends of the main strokes of letters, while sans-serif fonts lack these strokes, resulting in a cleaner, more modern look.

Usability (include typical usability tests)

Usability testing is a method of testing the functionality of a website, app, or product by observing real users as they attempt to complete tasks on it.

Sitemaps for Google (XML)

Sitemaps are an easy way for webmasters to inform search engines about pages on their sites or for crawling.

story board

A storyboard is a visual representation of a story or narrative, typically used to plan out the key scenes in a film, TV show, or commercial, by using a series of sketches or illustrations arranged in sequence.

Static and Variable web fonts (with code samples)

Static Fonts maintain a different file for each variation. Variable fonts maintain a single file having all the possible variations.

Card sort

Card sorting is a method which people place individually labeled cards into groups according to whats logical.
