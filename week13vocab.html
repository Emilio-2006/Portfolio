Vocabulary Page Week 13

Uniform Resource Locator (URL)

A URL is your address of a unique resource on the internet it is one of the key mechanisms used by browsers to retrieve published resources such as protocol as html pages css documents images and etc.

Firewall

It is a network security to separate internal trusted networks and external untrusted networks

Transmission Control Protocol-Internet Protocol (TCP-IP)

Is a set of rules that computers use to communicate over the internet. It breaks data into packets, send them, and ensure they arrive accurately at the destination

Network Protocols

A set of Rules that helps two devices share information over a single connected network

Computer Network

A group of devices that are connected and can share dat and resources

IPv4

IPv4 stands for Internet Protocol version v4, which is a set of rules that carry out how data is sent and received over the internet

IPv6

a networking standard that allows devices to communicate on the internet using IP addresses.

Domain Name Services (DNS)

A DNS converts domain names into IP addresses which then all over browsers to get to websites and other internet resources through these IP addresses

Hyper-text transfer protocol (HTTP/HTTPS)

The protocol is used connect to web server to send html pages to the user so they can surf the web.

File Transfer Protocol

is a standard network protocol that allows users to transfer files between computers on a network

Software Standards

Software standards is basically to where the standards or different computer programs one checked out all at the same time.

OSI Model

The OSI model describes seven layers of how a computer system communicates with a network.
