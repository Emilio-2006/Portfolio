    Vocabulary Page Week 7

    meta tag for charset The charset attribute specifies the character encoding for the HTML document.
    meta tag for keywords Meta keywords are meta tags used in HTML code that provide information about the page's content.
    meta tag for viewport The viewport meta tag in HTML is used to control how a webpage is displayed on different devices.
    meta tag for refresh Meta refresh is a method of instructing a web browser to automatically refresh the current web page or frame after a given time interval
    meta tag for author The tag defines metadata about an HTML document.
    Confidentiality (cybersecurity) part of AIC triad Confidentiality involves the efforts of an organization to make sure data is kept secret or private.
    Integrity (cybersecurity) part of AIC triad Integrity involves making sure your data is trustworthy and free from tampering.
    Availability (cybersecurity) part of AIC triad This means that systems, networks, and applications must be functioning as they should and when they should.
    White Hat Hacker (cybersecurity) A white hat hacker -- or ethical hacker -- is an individual who uses hacking skills to identify security vulnerabilities in hardware, software or networks.
    Black Hat Hacker (cybersecurity) Black Hat Definition. Black Hat Hackers refers to hackers with malicious intentions who gain unauthorized access to computer networks and systems.
    Requirements Traceability What Is Requirements Traceability? Requirements traceability is the ability to trace a requirement forwards and backwards in the development lifecycle.
    Iron Triangle (project management) a visual representation of the relationship between the scope, time, and budget constraints in project management.
