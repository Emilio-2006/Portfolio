Vocabulary Page Week 4

attribute

Attributes are properties or characteristics that can be assigned to elements like variables, objects, or classes in programming.

form and form action

The action of a form is the program that is executed on the server when the form is submitted. This property can be retrieved or set.

name attribute for inputs, textarea, checkboxes and radio buttons

The name attribute specifies the name of an < input > element

form method (post and get)

GET method is use to send the less sensitive data whereas POST method is use to send the sensitive data.

fieldset

The < fieldset > tag is used to group related elements in a form. The < fieldset > tag draws a box around the related elements.

legend

A legend is used to identify data in visualizations by its color, size, or other distinguishing features.

input (give at least 5 examples of different types)

In computing, "input" refers to data or instructions that are provided to a computer system, allowing users to interact with it and control applications; examples include typing on a keyboard, clicking a mouse, speaking into a microphone, scanning a document with a scanner, or touching a touchscreen.

label with for attribute

The "label" attribute associates the label with a specific form control using the "for" attribute, linking them together semantically.

radio buttons

Radio buttons, also called option buttons, let users select one option from a collection of two or more mutually exclusive, but related, options.

checkboxes

A check box is used to select or deselect action items.

textarea

Some parts of this feature may have varying levels of support. The < textarea > HTML element represents a multi-line plain-text editing control

button type submit and regular button

submit — Submits the current form data.
