Vocabulary Page Week 5

the "disabled" attribute

The disabled attribute is a boolean attribute that, when present, makes the element it is applied to unmodifiable, unfocusable, and non-submittable within a form.

the datalist tag, please include the "list" attribute

The datalist element's id attribute must be equal to the < input > element's list attribute

the "autocomplete" attribute

The autocomplete attribute allows the browser to do a pattern match against a list of values locally stored with the browser, and supplies the appropriate corresponding value when the input is programmatically tagged.

the input of type="search"

The < input type="search"> defines a text field for entering a search string.

the option tag, please include the difference between select and datalist

in the < datalist > tag the user can enter their input and add that as an option with the help of the < input > element whereas the < select > tag doesn't provide this feature.

the input of type="date"

elements of type="date" create input fields that let the user enter a date.

the select tag, please include size attribute

The size attribute specifies the number of visible options in a drop-down list. If the value of the size attribute is greater than 1, but lower than the total number of options in the list, the browser will add a scroll bar to indicate that there are more options to view.

the input type="number"

The < input type="number"> defines a field for entering a number. Use the following attributes to specify restrictions: max - specifies the maximum value allowed.

the input type="range"

The < input type="range"> defines a control for entering a number whose exact value is not important

the meter tag, include min, max, low, high and optimum attributes

The < meter > HTML element represents either a scalar value within a known range or a fractional value.

the progress bar, include important attributes

Attributes are used to understand the behavior of the elements in HTML.

the button "form" attribute

The form attribute specifies the form the button belongs to. The value of this attribute must be equal to the id attribute of a < form > element in the same document.
