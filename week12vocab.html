    Vocabulary Page Week 12

    Web framework (with examples) A web development framework is a set of resources and tools for software developers to build and manage web applications, web services and websites, as well as to develop application programming interfaces (APIs).
    Functional Testing Functional testing is a type of testing that seeks to establish whether each application feature works as per the software requirements.
    Non-functional testing Non functional testing is a type of software testing that verifies non functional aspects of the product, such as performance, stability, and usability.
    Content Management System (CMS) A content management system (CMS) is a web application or software that manages digital content, allowing multiple contributors to create, edit and publish from a single dashboard
    Unit Testing Unit testing is the process where you test the smallest functional unit of code.
    Integration Testing Integration testing -- also known as integration and testing or I&T -- is a type of software testing in which the different units, modules or components of a software application are tested as a combined entity.
    Regression Testing Regression Testing is a type of testing in the software development cycle that runs after every change to ensure that the change introduces no unintended breaks.
    Load Testing Load testing is a type of performance test that checks how systems function under the projected number of concurrent virtual users performing transactions over a certain period of time.
    Smoke Testing Smoke testing, also called build verification testing or confidence testing, is a software testing method that is used to determine if a new software build is ready for the next testing phase.
    Mocks, Mocking What is mocking? Mocking is a process used in unit testing when the unit being tested has external dependencies.
    Acceptance Testing Acceptance testing is. defined as "formal testing conducted to determine whether a. software system satisfies its acceptance criteria and to enable the customer to determine. whether to accept the system" [FIPSlOl].
    Test Driven Development (TDD) Test-driven development (TDD) is a software development practice that emphasizes writing tests before writing the actual code.
