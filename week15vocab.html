Vocabulary Page Week 15

Database table

Data stored in rows and columns in a much similar way to that of a spreadsheet, used to overall store all rational data into a relational database

Data normalization

Data normalization is the process of organizing data within a database to eliminate redundancy, improve data integrity, and ensure consistency, making it easier to manage, query, and analyze.

Database first normal form

First normal form (1NF) is a property of a relational database table that ensures each column contains only atomic (indivisible) values, and each record is unique

database normalization

the process of organizing the information in a database by creating tables and finding similarities to link the information inside the tables to a set of rules and regulations.

Data Visualization

the graphical representation of information and data, using visual elements like charts, graphs, and maps to make complex data easier to understand, analyze, communicate.

SQL Join

An SQL Join is used to combine data from multiple tables using matching keys.

One to One join

One to one join is a database that combines two related tables, containing the same information but separate.

One to Many join

A one to many relationship exists when a record in one table can be related to multiple records in another table.

SQL

its a programming language used for storing and processing information in a relational database. it is used in all types of application

Database/DBMS

A database management system (DBMS) is a software system for creating and managing databases.

Business Intelligence

Business intelligence (BI) is the process of collecting, analyzing, and presenting business data to help organizations make informed decisions and gain insights into performance and trends.

Many to Many join

A many to many relationship is when many items in one table have a relationship with many items in another table.
